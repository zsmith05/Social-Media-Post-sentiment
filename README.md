X post Sentiment Prediction Research- April 2026

This is my research project I did on comparing how different CNN and Transformer models perform on predicting X post sentiments. I developed deep learning models to classify sentiment across 74,000+ social media posts into positive, neutral, and negative categories.
Then I built a text preprocessing pipeline with missing-value handling, label encoding, and a 20,000-token vocabulary, using stratified sampling to preserve class distributions.
Finally I compared six CNN, Transformer, and hybrid model configurations, achieving a 0.900 macro F1-score on 7,469 validation posts with a tuned CNN.
